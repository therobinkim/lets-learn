# JSDN: JavaScript Diagram Notation

> **[gilbert/jsdn](https://github.com/gilbert/jsdn)** by Gilbert Garza

JSDN is a formalized way of visually simulating JavaScript execution. It's a diagram notation and set of simplified execution rules that make abstract concepts concrete.

## Why It's Worth Knowing

JSDN is one of the best resources I've found for building a mental model of how JavaScript actually works under the hood. The PDF walkthroughs cover:

1. **Variables and Function Calls** — how the stack and heap work
2. **More Function Calls** — nested calls, return values
3. **Functions as Arguments** — callbacks visualized
4. **Closures** — finally, closures that make sense
5. **Closures 2** — more advanced closure patterns
6. **Objects in Memory** — "pass by value" vs "pass by reference" demystified

Each lesson is a step-by-step diagram showing exactly what happens in memory as code executes. If you've ever been confused by closures or why mutating an object inside a function affects the original — start here.
